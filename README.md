## Design

I wanted the website to have a calm but modern look instead of using a very common portfolio template.

The main design uses a dark green background with cream/off-white sections and small teal, gold, and warm accent colors.

The CSS also includes:

* Hover effects on buttons and links
* Smooth scrolling
* Project card hover animations
* Responsive layouts
* Mobile navigation
* Different typography styles
* Focus styles for accessibility

The colors and typography are defined using CSS variables, which makes it easier to maintain the design throughout the website.

## Responsive Design

The website is designed to work on different screen sizes.

On smaller screens:

* Desktop navigation changes to a mobile menu
* Sections become single-column layouts
* Project cards stack vertically
* Text sizes adjust according to the screen
* The profile image and other elements resize accordingly

These changes are handled using CSS media queries.
